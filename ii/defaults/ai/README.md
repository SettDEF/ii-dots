# Prompt presets

Each file here is a system prompt the assistant can be switched to. Drop a
Markdown file in and it appears in the picker; `NoPrompt.md` is the empty one.

The `ii-` and `w-` presets are this project's own. A preset from
[Nyarch Assistant](https://github.com/NyarchLinux/NyarchAssistant) used to sit
here too and was removed, since it is GPLv3 and this repository is MIT.
